# Club-Fit

## Overview

Club-Fit is a web-based Fitness Club Management System designed to streamline and automate the daily operations of fitness centers and gyms. The platform provides dedicated functionalities for administrators, trainers, and members, enabling efficient management of memberships, workout plans, diet plans, and fitness records through a centralized system.

The project was developed using HTML, CSS, JavaScript, PHP, and MySQL to deliver a user-friendly and scalable fitness management solution.

## Features

### Administrator Module

* Manage member registrations and profiles
* Manage trainer accounts and records
* Monitor overall system activities
* Maintain centralized fitness club data

### Trainer Module

* Create and manage workout plans
* Assign personalized fitness programs
* Track member progress and records
* Update member fitness information

### Member Module

* Access personalized workout plans
* View diet recommendations
* Manage personal profile information
* Track fitness progress and activities

## Getting Started

### Prerequisites

* XAMPP
* PHP 7.x or above
* MySQL
* Web Browser
* Visual Studio Code (Optional)

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Move the project folder to the XAMPP `htdocs` directory.

3. Start Apache and MySQL services using XAMPP.

4. Import the database file into MySQL using phpMyAdmin.

5. Open the application in your browser:

```text
http://localhost/Club-Fit
```
